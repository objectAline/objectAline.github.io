qm-dev

A personal, self-hosted assistant — single operator, no public service.

qm-dev is a private deployment of qm, an open-source assistant, run by one individual on their own machine for their own use. It is not a product, not a service, and has no users other than its operator.

What it does

The operator chats with the assistant and asks it about their own Google data — for example “what is on my calendar tomorrow”, “find last week’s unread mail”, or “read this spreadsheet”. The assistant calls Google APIs on the operator’s behalf to answer.

What it asks Google for

  • Gmail — read messages and threads; create, edit, and send drafts. It cannot delete or trash mail.
  • Calendar — read and manage events.
  • Drive — read and download files; create new files. It cannot delete, rename, or move existing files.
  • Sheets, Docs, Slides — read and edit document content.
  • Tasks — read and manage task lists.

See the Privacy Policy for how this data is handled.
